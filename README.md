# Unicodax Professional Job Finder

A Gradio-based web app that searches tech jobs using the RapidAPI Job Search API and displays job stats by location.

## Features

- Base64 API key handling
- Search by job title & location
- Recent jobs only (posted in the past 7 days)
- Job distribution bar chart
- Export results as CSV

## How to Run Locally

```bash
pip install -r requirements.txt
python app.py
